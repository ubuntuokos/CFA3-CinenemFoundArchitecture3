# CFA3 official visual identity

**Brand:** CFA3 — Cinema Fund Architectura 3  
**Status:** APPROVED / canonical visual identity

The logo approved by the project owner is the official CFA3 parent-platform mark. New CFA3 applications, GUI/design plans, product mockups and startup/splash surfaces must use this identity unless the owner explicitly approves a replacement.

## Canonical identity fingerprint

The approved master artwork is a PNG with these immutable identity properties:

- dimensions: `1254 × 1254`
- SHA-256: `515523fae79403d2e949dd4fabf87bf1cf029c6361175f6562c5601bdd204846`
- visible lockup: `CFA3` and `CINEMA FUND ARCHITECTURA 3`
- motif: architectural CFA3 structure with cinematic film-strip treatment and black/gold visual language

The exact fingerprint prevents an AI-regenerated or silently altered logo from being mistaken for the approved master.

## Repository display asset

`docs/assets/branding/cfa3-logo-official-display.jpg` is the repository-safe display derivative of the approved mark.

- dimensions: `512 × 512`

- role: documentation, repository previews, GUI/design references
- authority: derivative only; it does not supersede the approved PNG master fingerprint

Technical resize/encoding derivatives are permitted when required by a target platform, but they must preserve the composition, wording, geometry, proportions and visual identity. A derivative must never redefine the master identity.

## Mandatory CFA3 usage

1. Every new CFA3 main application must use the official CFA3 identity in its product-branding surface.
2. CFA3 GUI and design plans must reference this official identity rather than inventing a replacement CFA3 logo.
3. Application-specific icons may coexist with the CFA3 parent identity, but they do not replace it.
4. Splash/launcher implementations must derive their CFA3 branding from this identity. The previously approved module-loading launcher treatment is a presentation/runtime component, not a different logo.
5. An alternate CFA3 main logo requires explicit project-owner approval.
